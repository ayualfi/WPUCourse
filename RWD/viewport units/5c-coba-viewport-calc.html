Eksplorasi Viewport Units & Fungsi calc()

Ketika unit viewport dikolaborasikan dengan fungsi calc(), kita dapat memecahkan masalah layout responsif yang rumit seperti tinggi hero banner dikurangi navbar, tipografi fluid dengan batas aman, hingga elemen meluber (breakout).

.hero-banner {

}
min-height: calc(100vh - navbar)

Hero Banner Setinggi Sisa Layar

Mengurangi tinggi navigasi statis (45px) dari tinggi layar penuh (100vh). Trik ini memastikan elemen hero pas mengisi sisa layar vertikal tanpa memicu kemunculan scrollbar halaman.

Uji Coba: Tarik tinggi browser Anda. Banner simulasi di atas akan menyesuaikan tingginya dengan sempurna tanpa menyisakan ruang kosong.

Fluid Text & Batas Aman

Ubah lebar browser Anda secara horizontal untuk menguji.

.fluid-title {
  font-size: calc(1.2rem + 2vw);
}
font-size: calc(1.2rem + 2vw)

Tipografi Fluid dengan Batas Minimum

Menggunakan unit vw agar ukuran teks membesar atau mengecil secara otomatis mengikuti lebar layar browser. Formula calc(1.2rem + 2vw) memberikan nilai dasar aman sebesar 1.2rem agar teks tidak mengecil secara ekstrem pada layar HP.

Padding Area: calc(15px + 1.5vw) 
.responsive-container {
  padding: calc(15px + 1.5vw);
}
padding: calc(15px + 1.5vw)

Padding Dinamis dengan Batas Aman

Menentukan ruang jarak (padding/margin) dalam elemen yang membesar secara proporsional sesuai lebar layar browser (1.5vw), namun tetap memiliki batas minimum yang aman sebesar 15px agar konten tidak menempel ke tepi layar pada perangkat HP/mobile.

Uji Coba: Ubah lebar browser Anda secara horizontal. Perhatikan bagaimana jarak (padding) antara kotak biru dan kotak abu-abu di atas menyusut dan melebar secara dinamis dan halus!

Ukuran Elemen Kuadrat Multi-Orientasi

Mengatur ukuran elemen persegi (seperti foto profil, logo, atau kode QR) agar tetap muat di layar baik dalam mode portrait (lebar lebih kecil) maupun landscape (tinggi lebih kecil). Rumus ini memastikan ukuran tidak melebihi tinggi layar pada posisi landscape.

Uji Coba: Tarik browser Anda secara horizontal dan vertikal bergantian. Kotak ungu di atas akan menyesuaikan ukurannya mengikuti dimensi layar yang paling kecil (lebar atau tinggi)!
Area Konten (padding-y: calc(20px + 2vmax)) 
.premium-section {

  padding-bottom: calc(30px + 4vmax);
}
padding: calc(30px + 4vmax) 0

Jarak Section Premium (Skala Dimensi Terbesar)

Mengatur padding atas/bawah halaman yang menyesuaikan diri dengan dimensi layar terbesar (lebar atau tinggi). Teknik ini sering dipakai pada landing page premium agar jarak antar bagian terasa pas dan lega baik di layar ultra-wide maupun layar monitor tinggi.

Uji Coba: Ubah tinggi atau lebar browser Anda. Kotak di atas akan mengecil/membesar mengikuti perubahan ukuran dimensi layar terbesar Anda!
