Eksplorasi Fungsi calc() Murni

Belajar melakukan kalkulasi matematis dinamis langsung di dalam CSS untuk merancang tata letak web secara presisi.

Bagian 1: Penggunaan Fungsi calc() dalam Tata Letak

Fungsi calc() memungkinkan kita untuk melakukan perhitungan nilai properti CSS (seperti width, margin, padding, dsb). Keunggulan terbesarnya adalah kemampuan mencampur berbagai unit (seperti menggabungkan % dengan px).

Kolom Kiri calc(50% - 15px)
Kolom Kanan calc(50% - 15px) 
.col-half {
  width: calc(50% - 15px);
}
width: calc(50% - gap/2)

Membagi Kolom Sejajar dengan Celah

Ketika membuat layout 2 kolom dengan celah (gap) sebesar 30px, jika kita memberi masing-masing kolom width: 50%, kolom kedua akan terdorong ke bawah. Rumus calc(50% - 15px) memotong setengah dari lebar celah (15px) pada masing-masing kolom sehingga muat sejajar dengan sempurna.

Penting: Spasi di sekitar operator kurang (-) dan tambah (+) wajib ditulis. Contoh: calc(50%-15px) tanpa spasi dianggap error oleh browser.
Sidebar (200px)
Area Konten Utama Lebar Area = calc(100% - 200px) 
.main-content {
  width: calc(100% - 200px);
}
width: calc(100% - sidebar)

Menggabungkan Persentase dan Piksel

Dalam pembuatan dashboard, kita sering mengunci lebar sidebar (misal: 200px) agar menunya tidak bergeser. Dengan calc(100% - 200px), lebar area konten utama akan otomatis menghitung sisa ruang layar secara dinamis.

Petunjuk Uji Coba: Ubah ukuran lebar browser Anda. Kolom sidebar akan tetap selebar 200px sedangkan area konten utama akan melebar/menyempit secara elastis.
