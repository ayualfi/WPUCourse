Aturan Emas Gambar Responsif

Perbedaan antara Gambar Default, penggunaan width: 100%, dan max-width: 100%.

1. Gambar Tanpa CSS (Default) Bug Overflow

Gambar di bawah memiliki resolusi asli lebar 600px. Ketika diletakkan di dalam kontainer yang lebarnya dibatasi hanya 300px (kotak garis putus-putus merah), gambar akan meluber keluar karena tidak memiliki aturan responsif.

2. Menggunakan width: 100% Pecah / Upscaled

Gambar di bawah memiliki resolusi asli 600px, ditaruh di kontainer lebar 800px. Menggunakan width: 100% memaksa gambar melebar mengikuti kontainer induknya, sehingga gambar menjadi pecah, blur, dan melar melebihi resolusi aslinya.

3. Aturan Emas (max-width: 100% & height: auto) Solusi Terbaik

Menggunakan max-width: 100% dan height: auto. Jika kontainer lebih kecil dari ukuran gambar asli, gambar akan mengecil secara fluid. Namun, jika kontainer lebih besar (lebar 800px), gambar berhenti membesar di batas resolusi aslinya (600px) sehingga ketajaman gambar tetap terjaga dan tidak blur.

4. Mengunci Tinggi Tetap (Tanpa Object-Fit) Problem Gambar Gepeng

Kenapa setelah diberi height: auto, sering kali muncul area kosong di kiri-kanan jika container-nya tinggi? Kenapa tidak sekalian kita beri height: 100% (atau tinggi tetap)? Jika kita memaksa tinggi gambar (misal height: 200px dan width: 100%) tanpa pelindung, gambar akan dipaksa meregang memenuhi kotak dan aspek rasionya hancur (tertarik gepeng).
